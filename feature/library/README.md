# :feature:library

Your Library and everything you reach from it.

- Library shell: `LibraryScreen`, `LibraryTabs` (Music, Podcasts, Audiobooks), `LibraryLists`, `LibraryControls`, `MusicPageLoading`, `BrowseScreens`.
- Pages: `AlbumScreen`, `ArtistScreen` with `ArtistLayout`, `InfoSections`.
- Collections, shared by the playlist, mix, genre and liked pages: `CollectionScreen`, `CollectionHeader`, `CollectionSongList`, `CollectionSelection`, `CollectionDownloadDialogs`, `LikedGenreMixScreens`.
- Playlists: `PlaylistScreen`, `PlaylistEditScreen`, `PlaylistMenu`, `PlaylistSharingUi`.
- `LocalBookRows` — the Audiobooks tab's phone-book list.
- `LibraryRoutes.kt`.

Tests: `LibraryTabsTest`, `LibraryScreenshots`.
